# MiniFugg — Parallax Lab (RETIRED)

The Parallax Lab was the desktop tuning tool for the old React/CSS layered-cover renderer. It was removed during the earlier TetraMindFck layered-cover experiment.

**Do not add new production cover capabilities to this system.**

The approved target is static cover art rendered by Core. The Phaser cover runtime was removed when the accepted static TetraMindFck set became canonical.

## What was preserved

Git history preserves the useful authored information from the former TetraMindFck experiment:

- layer selection;
- scale/position/rotation/opacity;
- parallax amplitudes;
- motion intent;
- unlock scores;
- existing raster asset paths.

The former Lab implementation, browser-only drafts, layer data and `PhaserCoverHost` are available through Git history. Current `src/games/calc-drop/welcome.ts` contains only the canonical static cover variants.
