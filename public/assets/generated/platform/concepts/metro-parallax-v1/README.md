# Metro parallax v1

Production source set for the approved 20% closer MiniFugg metro entry scene.

- `carriage-foreground-extraction-source.png` is an image-generation extraction study. Its visible RGB is not shipped. The build script reads only its neutral checker regions as an alpha matte, then applies that matte to the exact approved `camera-distance-20.png` pixels.
- `exterior-panorama-source.png` is the authored outdoor-only low-poly panorama used behind the windows.

The production derivatives live in `entry-scenes/metro-sunset/parallax/` and are rebuilt with `scripts/build-metro-entry-parallax-assets.py`. The scene geometry, passengers, phone and arm are never regenerated by this split. Runtime serves lossless WebP with PNG fallback.

Target motion ownership:

1. sky and sun: slow drift;
2. skyline: medium drift;
3. water and reflections: faster drift;
4. carriage and passengers: fixed;
5. floor light: independent interior response.
