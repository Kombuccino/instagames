## Concepts archivés

### Access Granted?
Faux écran d’accès qui est déjà le jeu : questions de plus en plus improbables à réussir avant d’atteindre un mini-runner volontairement nul comme chute comique.  
GitHub : https://github.com/Kombuccino/instagames/blob/main/docs/game-ideas/GAME_IDEA_access_granted.md

### Alcatrax
Hide-and-seek inversé : contrôler un projecteur et repérer les prisonniers qui s’évadent au milieu de faux signaux ; chaque mauvais coup de spot impose un cooldown.  
GitHub : https://github.com/Kombuccino/instagames/blob/main/docs/game-ideas/GAME_IDEA_alcatrax.md

### Black Mines
Exploration / extraction minière fin XIXe-début XXe : mineurs couverts de charbon, rails, cages, ombres et lumières chaudes. En descendant trop profondément, la mine perce un autre monde aux couleurs radicalement différentes.  
**Drive :** https://drive.google.com/file/d/1ZrMePjDgWTh4r6-w3840c5ip2I3ZfUwZ/view  
GitHub : https://github.com/Kombuccino/instagames/blob/main/docs/game-ideas/GAME_IDEA_black_mines.md

### Chicken Army
Incremental court : faire grandir des poussins jusqu’à former une armée de Chicken Soldiers, avant une conclusion où les humains gagnent et transforment tout le monde en fast-food.  
GitHub : https://github.com/Kombuccino/instagames/blob/main/docs/game-ideas/GAME_IDEA_chicken_army.md

### CrossBeat Tokyo
Jeu 3D léger de rythme et d’esquive dans des passages piétons japonais bondés, au son d’une City Pop / technopop / arcade japonaise 70s–80s.  
GitHub : https://github.com/Kombuccino/instagames/blob/main/docs/game-ideas/GAME_IDEA_crossbeat_tokyo.md

### Greedy Little Dwarf
Mini city-builder voxel vertical : les nains creusent automatiquement sous leur colonie pour les ressources, provoquant effondrements, morts et destruction des bâtiments.  
GitHub : https://github.com/Kombuccino/instagames/blob/main/docs/game-ideas/GAME_IDEA_greedy_little_dwarf.md

### Kill Roro
Jeu d’observation sous pression : retrouver le vrai bouton rouge relié à Roro avant la fin du chrono au milieu de boutons, caches, nuances et faux câbles.  
GitHub : https://github.com/Kombuccino/instagames/blob/main/docs/game-ideas/GAME_IDEA_kill_roro.md

### Ma2t the Dev
Arcade de défense du flow : neutraliser les vraies perturbations de l’open space sans toucher les innocents pour garder le code propre, rapide et vert.  
GitHub : https://github.com/Kombuccino/instagames/blob/main/docs/game-ideas/GAME_IDEA_ma2t_the_dev.md

### Pigeon versus Darwin
Runner / prise de risque vertical : Dash + Picorer ; plus la nourriture est proche du danger, plus elle vaut cher. Verdict : PIGEON WIN ou DARWIN WIN.  
GitHub : https://github.com/Kombuccino/instagames/blob/main/docs/game-ideas/GAME_IDEA_pigeon_vs_darwin.md

### Pump! Pump! Pump!
Runner vertical grotesque avec personnages ou animaux possédant trois zones absurdes à gonfler, puis à protéger des obstacles piquants.  
GitHub : https://github.com/Kombuccino/instagames/blob/main/docs/game-ideas/GAME_IDEA_pump_pump_pump.md

### Quickit Quickit Dungeon
Dungeon speedrun procédural ultra-court : 10 secondes de prescience, puis brouillard de guerre, objectifs obligatoires, exécution de mémoire et optimisation du meilleur temps.  
GitHub : https://github.com/Kombuccino/instagames/blob/main/docs/game-ideas/GAME_IDEA_quickit_quickit_dungeon.md

### Reverse Tetris
Tetris inversé : le jeu construit la matière et le joueur la déconstruit ; piste privilégiée avec des tétriminos de vide qui remontent et creusent une masse descendante.  
GitHub : https://github.com/Kombuccino/instagames/blob/main/docs/game-ideas/GAME_IDEA_reverse_tetris.md

### Spanky Bonga
Jeu de rythme grotesque : un personnage ou animal à quatre pattes sert de percussion vivante, avec quatre zones de frappe et plusieurs morceaux de difficulté croissante.  
**Drive :** https://drive.google.com/file/d/1KHPqkZId-Y9QowIjUiFjqw5jyFzjKWPT/view  
GitHub : https://github.com/Kombuccino/instagames/blob/main/docs/game-ideas/GAME_IDEA_spanky_bonga.md

### Spirit Fisher
Jeu de pêche d’ambiance en esthétique estampe japonaise. Le joueur remonte des poissons-esprits / yōkai / oni articulés comme des marionnettes de papier, les collectionne ou les vend, améliore sa barque et part toujours plus loin et plus profond.  
**Drive :** https://drive.google.com/file/d/1v4tykq4tMz70uVCs5KzzLTvmDZoMpeDJ/view  
GitHub : https://github.com/Kombuccino/instagames/blob/main/docs/game-ideas/GAME_IDEA_spirit_fisher.md

### Splasher
Jeu tactile de précision / remplissage : canon directionnel, pression à pomper, jet instable à corriger, récipients absurdes à remplir avant la fin du chrono.  
GitHub : https://github.com/Kombuccino/instagames/blob/main/docs/game-ideas/GAME_IDEA_splasher.md

### Tetra Gravity
Tetris-like carré à gravité variable : changer la gravité réorganise toutes les pièces mais en ajoute aussi de nouvelles ; supprimer les lignes plus vite que le plateau ne se remplit.  
GitHub : https://github.com/Kombuccino/instagames/blob/main/docs/game-ideas/GAME_IDEA_tetra_gravity.md

### The Stomac
Jeu d’adresse et de collecte dans l’estomac : chaque aliment digéré libère des éléments utiles et des saloperies ; récupérer ce qui nourrit l’organisme et éviter d’absorber les déchets.  
GitHub : https://github.com/Kombuccino/instagames/blob/main/docs/game-ideas/GAME_IDEA_the_stomac.md

## Comment reprendre un concept

1. Ouvrir ce fichier dans Drive.
2. Choisir le concept et ouvrir sa fiche Drive lorsqu’elle existe, sinon son lien GitHub détaillé.
3. La fiche conserve le concept, la boucle, les décisions, la V0 et les points de vigilance.
4. Relire `docs/ACTIONS.md` avant tout travail MiniFugg.
5. Tant que le jeu reste dans l’incubateur, aucun compteur 10 prompts.
6. Quand l’utilisateur demande explicitement de développer le jeu, passer dans le pipeline normal.

## Règle d’archivage future

Toute nouvelle idée de jeu doit désormais être :
- documentée en fiche détaillée ;
- sauvegardée dans `Game Concept/Ideas` sur Drive pour lecture utilisateur ;
- reflétée dans `docs/game-ideas/` sur GitHub pour continuité ChatGPT/Codex ;
- ajoutée à cet index ;
- mise à jour dans la même fiche si elle évolue, sans V2/V3 inutiles.

Toute nouvelle planche de recherche / moodboard doit être sauvegardée dans `Game Concept/Moodboards` avec un nom descriptif. Les directions explicitement rejetées restent identifiées comme telles.
