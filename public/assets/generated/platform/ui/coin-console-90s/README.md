# MiniFugg Core — coin console 90s

Production assets for the full-width Core cover console selected on 12 September 2026.

- `sources/coin-fuggy-user-reference.png` is the original coin supplied and approved by the user. It is kept as the immutable visual reference.
- `masters/coin-fuggy-reference.png` is the cleaned, full-resolution RGBA master with true transparency. This exact design is canonical for every MiniFugg coin use; do not redraw or substitute it.
- `masters/` preserves the transparent PNG components at their original extracted resolution.
- Root-level WebP files are lossless runtime derivatives generated by `scripts/build-core-coin-console-assets.py`.
- The chassis is immutable at runtime. PREV and NEXT use independent state images aligned to their physical wells.
- PLAY uses `play-states-atlas.webp`: four equal `224 × 140` runtime cells in the order idle, medium glow, peak glow and pressed. Its PNG master uses four equal `545 × 357` cells. Every frame shares the exact idle bezel; only the illuminated inner face changes.
- `coin-fuggy.webp` is the `192 × 192` lossless runtime source used by compact Core indicators; CSS displays it at `20 × 20` or `14 × 14` according to context.
- The counter embeds the same canonical coin at approximately `27 × 31` displayed pixels inside its physical socket at the `390`-unit reference width.
- Coin insertion uses `coin-insert-three-quarter.webp`, a deterministic perspective derivative of the canonical face in a `96 × 96` transparent cell. It slides a short horizontal distance into the slot mask; the old four-frame face-to-edge swap is no longer used at runtime.
- The counter value, `-1` feedback and coin insertion paths remain live Core UI rather than baked artwork.

Validated visually at `390 × 844` and in the PC `390 × 662` frame. TetraMindFck uses intact poster fitting on wider PC frames so the console does not hide the main character.
